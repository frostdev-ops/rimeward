# Rimeward desktop 0.5.7 / web 0.23.7

This release combines browser access and document downloads, remote project
reliability, and Remote Desktop lifecycle, performance and interface improvements.

- Rime and browser controls reach the browser's owning computer. Downloads are
  retained privately, can be imported into a conversation, and support PDF text
  searches and rendered page inspection.
- Remote projects avoid nested routing and stale sessions. Editors and terminals
  reconnect with bounded retries while preserving ownership and recovery data.
- Remote Desktop adds native browser fullscreen and integrated controls, shares
  capture where possible, and fixes stalled media starts, grant renewal, input
  cleanup and transfer validation. Packaging rejects incomplete media SDK caches.

The combined source passed all 481 existing Node tests, TypeScript, desktop lint,
UI goldens and remote workspace smoke checks. Isolated browser relay/download/PDF
checks, native desktop checks, packaged Node runtime checks and generated media
checks also passed. The release workflow separately verifies the committed app,
signing, production deployment and all three distributed installer builds.

Real-screen performance improvements are not quantified. Installed Windows,
X11/Wayland and physical mobile behavior remain platform acceptance work; generated
fixtures do not establish those results. Browserbase and legacy app CDP downloads
were not exercised. No model calls were made during these checks.

See [browser downloads](../browser-downloads.md), [remote project audit](../remote-project-audit.md)
and [Remote Desktop audit](../remote-desktop-audit.md) for the detailed changes and limits.
